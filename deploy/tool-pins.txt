# The versions of the tools the apptown runs for projects: the agent image's
# downloads and packages, the scanners, the sh checks' image and the private
# Docker sidecar. One version per tool. The versions are still written where
# they are used (the agent Dockerfile's ARG beside its SHA-256 sums, the
# scanner images in stock/scanners.yaml, the integration catalog's presets);
# `make check-pins` (scripts/pins-check.py) fails where one of those differs
# from this list, where the agent Dockerfile or stock/scanners.yaml pins a
# tool this list does not name, and where a tool here is pinned nowhere.
# To change a version: change it here, run `make check-pins`, change what it
# names (and the SHA-256 sums beside a Dockerfile ARG).
#
# Each line: tool, version, then where it is pinned, comma-separated:
#   image R   every R:<tag> whose tag starts with a version; the version is
#             the tag up to its first "-" (1.27.0-alpine is 1.27.0)
#   arg A     ARG A=<version> in deploy/apptown-agent/Dockerfile
#
# Not here: AppTown's own build and CI toolchain (go.mod, .gitlab-ci.yml,
# deploy/ci-heavy, cmd/apptown-gate), and what a project owns once adopted
# (stock/toolchains, stock/seeds).

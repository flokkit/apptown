The board asks me every month "how much fuel spend can't we account for?". I
want that as one number at the top of the report page, with the last 12 months
next to it so I can see if it's getting better.

To be clear about what I mean: dollars in mismatches that are still not
explained at the end of the following month. Explained ones don't count.
Referred ones that the depot hasn't answered do count.

If a month hasn't been run yet, show that, don't show zero.

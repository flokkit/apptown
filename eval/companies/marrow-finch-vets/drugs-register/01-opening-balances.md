To start using the register each clinic needs its opening balance for each drug.
The clinic managers will do a count with a second person on Monday 26 October
and type the results into a spreadsheet, one row per clinic, safe and drug,
with the counted quantity, the balance in the paper book, and the two names.

Please load these as an opening entry for each drug, clearly marked as
"opening balance carried forward from paper register, book number X, page Y",
not dressed up as a delivery. If the count and the book don't match, load the
counted figure and list the mismatches for me; I'll investigate those myself.
Don't load any row that has only one name on it.

I expect some mess: drug names written differently ("Methadone 10mg/ml",
"methadone inj"), and at least one clinic will put ml in the tablets column.
Ask me rather than guess.

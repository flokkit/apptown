Now there are 40-odd applications on the list at a time, people can't
find the one near them. Can we have:

- filter by town, and a search box for street name
- a small map on each application's page showing where the property is
- a list sorted by closing date, soonest first

The site still has to work for someone on a screen reader or with
JavaScript turned off. If the map can't load, the address alone is fine.

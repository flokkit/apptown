We've had a formal complaint from a resident who is blind. She couldn't
use the bin day lookup with her screen reader (the town list doesn't
announce itself) and the news photos have no descriptions. She's copied
in the Mayor and the state disability commissioner's office.

Until now accessibility has been "try to remember". From now on it's a
rule for every page residents can see, on all our public sites: the
website, Planning Notices, the hall booking pages, the Main Street site,
and the public pothole map.

- Every public page must pass an automated WCAG 2.2 AA check before it
  goes live. If it fails, it doesn't go live.
- Any new image needs alt text, or an explicit "decorative" marker.
- Forms must be usable with a keyboard alone and announce their errors.
- Fix what's already live, starting with the bin lookup. I need to tell
  the resident by the 30th what we've done.

Sione will do a manual screen-reader check on anything big, but the
automatic check is the minimum, and I'd like to be able to show which
check each page passed when it went live.

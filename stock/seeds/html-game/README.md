# Egg Catch

A small browser game: move the basket to catch the eggs a chicken drops.
It is the starting point for this project; ask for changes in the chat to
turn it into your own game.

## Run

Open `index.html` in a browser. There is nothing to install or build.

Arrow keys move the basket; on a phone or with a mouse, drag it. When the
game ends, Space or a tap starts a new one.

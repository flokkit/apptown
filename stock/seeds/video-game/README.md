# Star Drive

A small 3D browser game: drive a car around a field and collect stars. It
is the starting point for this project; ask for changes in the chat to
turn it into your own game.

## Run

    npm ci
    npm run dev      # play at the address it prints
    npm run build    # the finished game, as static files in dist/

Keys: W/S or the arrow keys drive, A/D steer. Touch or mouse: hold the
screen to drive, hold left or right of the middle to steer, hold near the
bottom to reverse. The play link always shows the latest landed game.

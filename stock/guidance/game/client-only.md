This is a client-only browser game: it runs entirely from the files in this repo. No network calls, no external script/style/font URLs, no CDNs, no analytics. The one exception is optional: sending errors to the attached error reporting, and showing the attached feedback widget. Their addresses arrive in `window.__APPTOWN_ENV__` from `/_apptown/env.js` (guidance `deploy/browser-values`), never written into the code, and the game plays exactly the same when they are absent. Gameplay, saves, scores and assets never depend on an attached service. Everything the game needs lives here — so it works offline, works from file://, and has nothing to leak. State that must survive a reload (high scores, saves) lives in localStorage. If an idea seems to need a server (multiplayer, shared leaderboards), it is out of scope for this project class — say so instead of building it.

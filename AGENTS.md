# AGENTS.md

The project guide for any agent is [CLAUDE.md](CLAUDE.md): what AppTown is,
its principles, design boundaries and working rules. It links to the owners of
current commands and implementation details. Text a person reads follows
[How AppTown writes](design/writing.md). Web changes follow the
[component map and stylesheet rules](web/DESIGN.md).

The maintainers' working-document conventions are in `private/AGENTS.md`, in
their private repository (checked out at `private/` when present).
